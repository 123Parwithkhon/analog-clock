# 🕒 Interactive Analog Clock

A beautiful and stylish real-time analog clock built using modern web technologies. The clock hands (hour, minute, and second) move smoothly according to the current system time.

## 🚀 Features
* Real-time dynamic time updates every second using JavaScript.
* Stylish gradient background and elegant clock face design.
* Precise rotation angle calculation for the hands (`transform: rotate()`).

## 🛠 Technologies Used
* **HTML5**
* **CSS3** (Positioning, clock hand styling, background images)
* **JavaScript (ES6+)** (Date objects, `setInterval`, DOM manipulation)

## 💻 How to Run
1. Clone or download this repository.
2. Open the `index.html` file in any web browser.
